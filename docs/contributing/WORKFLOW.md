# Contribution Workflow

1. Create a feature branch from `main`.
2. Link changes to a requirement or issue.
3. Keep commits focused and descriptive.
4. Add or update tests for behavior changes.
5. Include migration rollback/forward notes where relevant.
6. Never include secrets or real customer financial documents.
7. Request review for security, privacy, policy and data-model changes.
8. Merge only after checks pass and required approvals are recorded.
